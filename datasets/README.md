# Datasets

Store teaching datasets here only when redistribution is permitted. For data that cannot be included, provide a source link and acquisition instructions.

Include documentation alongside each dataset with:

- Source URL, creator, citation, and access date where relevant.
- Applicable license or terms and any redistribution restrictions.
- Whether the data are observed, synthetic, or modified, with preparation steps.
- A data dictionary describing variables, units, coding, and missing values.
- Relevant sampling context and limitations.

Exclude private or identifiable information. Keep original data separate from derived data and document transformations.
