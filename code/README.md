# Code

Store analysis scripts, demonstrations, and simulations here. Organize each example in its own descriptive directory when it needs multiple files.

For each example, document:

- The research question or concept it illustrates.
- Dependencies and versions, environment setup, and how to run it.
- Input data paths and expected outputs.
- Random seeds for simulations or other stochastic steps.

Use relative paths and include an environment or dependency file when needed to reproduce the analysis.
